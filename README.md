# Português de volta

**Экспресс-курс бразильского португальского за 6 недель: грамматика, фразы для поездки, диалоги, карточки и тесты — с озвучкой и офлайн-режимом.**

🔗 [Открыть курс →](https://anreiamirov.github.io/portugues-de-volta/)

---

## Что внутри

- **План на 42 дня** — по 30–40 минут в день, с отметками прогресса
- **15 тем грамматики** — от произношения до времён, с пошаговыми разборами фраз и упражнениями
- **Около 250 фраз по ситуациям** — магазин, ресторан, транспорт, аренда машины, аптека, пляж
- **12 диалогов** с режимом роли: свои реплики произносишь вслух, потом проверяешь
- **Карточки и тесты** по лексике и грамматике
- **Офлайн-режим** — сайт устанавливается на телефон и работает без интернета

Сайт статический и работает на GitHub Pages без сервера и без сборки фронтенда.

## Архитектурные решения

**Контент отделён от кода.** Всё, что меняется при работе над курсом, лежит в `data/`. Добавить фразу, диалог или упражнение можно без знания JavaScript.

**Без сборщика.** Код — нативные ES-модули, которые браузер загружает напрямую. Нет `node_modules`, нет шага сборки, который может сломаться. Node нужен только для проверки контента.

**Относительные пути.** Корень сайта вычисляется от расположения модулей (`core/paths.js`). Поэтому один и тот же код работает на `username.github.io/repo/`, на собственном домене и на `localhost`.

**Офлайн по умолчанию.** Service worker кэширует оболочку, данные и тексты грамматики при первом визите. Страницы и данные загружаются по схеме «сначала сеть, потом кэш», поэтому онлайн вы всегда видите свежую версию. Озвучка кэшируется отдельно, её можно скачать целиком кнопкой в настройках — это пригодится в поездке без роуминга. Версия кэша обновляется при каждом деплое: workflow подставляет хэш коммита вместо `__BUILD__` в `sw.js`.

**Двухуровневая озвучка.** Если есть заранее записанная нейросетевая озвучка (`audio/`), сайт проигрывает её. Если записи нет, фраза читается системным голосом устройства. Лучший системный голос выбирается автоматически. Ключ записи — нормализованный текст фразы, функция `clean()` одинакова в `speech.js` и `generate_audio.py`.

**Прогресс хранится в браузере** (`localStorage`, ключи `pdv:*`): отмеченные дни, выученные карточки, лучший результат теста. Сервер и аккаунты не нужны. Обратная сторона: прогресс не синхронизируется между устройствами.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и отправьте в него файлы проекта:
   ```bash
   git init
   git add .
   git commit -m "Первая версия курса"
   git branch -M main
   git remote add origin https://github.com/AnreiAmirov/portugues-de-volta.git
   git push -u origin main
   ```
2. В репозитории откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
3. Откройте вкладку **Actions**: workflow «Проверка и публикация» запустится автоматически. Если он стартовал до смены источника в Pages, запустите его вручную кнопкой **Run workflow**.
4. Сайт будет доступен по адресу `https://anreiamirov.github.io/portugues-de-volta/`.

Каждый следующий `git push` в `main` проверяет контент, догенерирует озвучку для новых фраз и публикует сайт. В pull request выполняется только проверка.

## Нейросетевая озвучка

Workflow генерирует mp3 для всех фраз голосами `pt-BR-FranciscaNeural` (основной) и `pt-BR-AntonioNeural` (твои реплики в диалогах). Используется библиотека [edge-tts](https://github.com/rany2/edge-tts). Готовые файлы хранятся в кэше GitHub Actions, а не в git, поэтому репозиторий остаётся лёгким. При следующих запусках генерируются только новые фразы.

Важно: edge-tts обращается к сервису озвучки браузера Edge. Это неофициальный способ, и сервис может изменить условия или временно блокировать запросы. На этот случай шаг генерации не останавливает публикацию: сайт выйдет, просто без записей, и будет использовать системный голос. Для надёжного долгосрочного решения замените функцию `synth()` в `scripts/generate_audio.py` на официальный API — Azure Speech (те же голоса) или Google Cloud Text-to-Speech. Ключ храните в **Settings → Secrets and variables → Actions**.

Локальная генерация (нужен Python 3.10+):
```bash
pip install edge-tts
python3 scripts/generate_audio.py
```

## Локальный запуск

ES-модули и `fetch` не работают при открытии `index.html` как файла, нужен локальный сервер:
```bash
python3 -m http.server 8000
```
Затем откройте `http://localhost:8000`. Service worker на `localhost` тоже работает. Если после правок видите старую версию, обновите страницу — оболочка загружается по схеме «сначала сеть».

Проверка контента перед коммитом:
```bash
node scripts/validate.mjs
```

## Как добавлять контент

**Фраза** — в нужную тему `data/vocab.json`:
```json
{ "pt": "Tem mesa para dois?", "ru": "Есть столик на двоих?", "note": "необязательная подсказка" }
```
Новая тема — объект с уникальным `id` (латиница, цифры, дефис), `name`, `note` и `items`. В теме должно быть не меньше 4 фраз, иначе в тесте не хватит вариантов ответа.

**Диалог** — в `data/dialogs.json`. Реплики ученика помечаются `"who": "Você"` (задаётся полем `learner`).

**Тема грамматики:**
1. Создайте `data/grammar/16-slug.html`. Португальские фразы оборачивайте в `[[...]]` — они станут озвучиваемыми. HTML внутри `[[...]]` не допускается.
2. Добавьте запись в `data/grammar/index.json`: `id`, `title`, `week`, `file`, упражнения в формате `{ "q": "...", "a": "правильный", "wrong": ["неверный", "..."] }` и при необходимости `razbors`.

**Новый JS-модуль** добавьте в список `CORE` в `sw.js`, иначе он не будет доступен офлайн. Валидатор напомнит об этом.

## Возможное развитие

- Собственный домен: файл `CNAME` в корне и настройка в **Settings → Pages**.
- Синхронизация прогресса между устройствами — потребует бэкенда (например, Supabase) и авторизации.
- Интервальное повторение карточек (SM-2) вместо текущей схемы «знаю / ещё раз».
- Тесты интерфейса на Playwright в том же workflow.
