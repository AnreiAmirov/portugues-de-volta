МужскойЖенский
Определённый[[o]] / [[os]][[a]] / [[as]]
Неопределённый[[um]] / [[uns]][[uma]] / [[umas]]

Обычно -o — мужской род, -a — женский. Частые исключения: [[o dia]], [[o mapa]], [[o problema]]; [[a mão]], [[a foto]]. Окончания -ção, -dade, -gem — женский род: [[a informação]], [[a cidade]], [[a viagem]].

ОкончаниеМножественное
гласная + s[[a casa → as casas]]
-m → -ns[[o homem → os homens]], [[o trem → os trens]]
-ão → чаще всего -ões[[a estação → as estações]] (но [[pães]], [[mãos]])
-l → -is[[o hotel → os hotéis]], [[o real → os reais]]
-r, -z → -es[[a mulher → as mulheres]], [[o mês → os meses]]

Прилагательное идёт после существительного и согласуется с ним: [[uma cerveja gelada]], [[dois sucos naturais]].
